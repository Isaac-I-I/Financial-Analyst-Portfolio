# 🏦 Asset-Backed Securitization (ABS) Model: Mittens Bank 2026-1

## 📌 Project Overview
This project features a fully dynamic, end-to-end Asset-Backed Securitization (ABS) model built entirely in Excel. It simulates the structuring of a **₦2.707 Billion ($2.707B)** consumer loan portfolio to provide liquidity and free up regulatory capital for a fictional lender, Mittens Bank.

This is not a static template—it is a fully functioning cash-flow engine driven by data. 

## 🔍 What's Inside the Model?

*   **Data Cleaning & Analysis:** Analyzed a raw **270,000-row** loan tape to isolate a clean, eligible pool of 170,461 active consumer loans.
*   **Vintage Loss Analysis:** Conducted historical performance analysis on mature vintages (2019–2022) to justify a Base Case Conditional Default Rate (CDR) of 6% and a Prepayment Rate (CPR) of 10%.
*   **Dynamic Amortization Engine:** Built a month-by-month cash flow engine modeling scheduled principal, prepayments, defaults, and recovery rates. 
*   **Pro-Rata Cash Flow Waterfall:** Structured a 3-tranche deal (Tranche A: $2B Senior, Tranche B: $500M Mezzanine, Equity: $207M) utilizing a pro-rata principal distribution to prevent mezzanine starvation.
*   **Yield & WAL Outputs:** Calculated that Tranche A achieves a Weighted Average Life (WAL) of 35 months and an expected investor yield of **11.56%**, while Tranche B yields **17.33%**.
*   **Stress Testing:** The model includes a built-in Stress Case scenario (doubling defaults to 10% CDR and dropping recovery rates to 20%) to test structural resilience and credit enhancement.

## 📂 The Deliverables
*   **`Mittens_Bank_ABS_Model.xlsx`**: The full Excel model including the Loan Tape, Stratification, Amortization Engine, and Waterfall. 
*   **`Mittens_Bank_Deal_Memo.pdf`**: A 3-page investment memo summarizing the deal structure, collateral metrics, and risk analysis.
